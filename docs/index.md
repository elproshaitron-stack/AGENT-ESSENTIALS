# Agent Essentials

**The missing toolkit for AI agents** — design, validate, optimize and scale AI
agents *before* you ship them to production. It is **not** an agent framework and
does not run your agents; it helps you make the decisions that come first.

## Modules

- [Architecture Generator](modules/architecture.md) — stack, RAG, memory, scaling & cost
- [Memory Engine](modules/memory.md) — save / retrieve / summarize / pack context
- [Task Planner](modules/planning.md) — goal → milestones, tasks, deps, risks
- [Hallucination Detector](modules/validation.md) — output risk scoring
- [Entailment Validator](modules/entailment.md) — per-claim NLI (pluggable scorer)
- [Token Counter](modules/optimization.md) — tokens, cost, model comparison
